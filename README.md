A make.fun entry for [The Best Advice I Ever Got](https://make.fun/competitions/u-pangg7-the-best-advice-i-ever-got-358cefb0): one sentence about the best advice the writer ever received, written by a small Python program.

## The line

> My grandmother kept a spare key under the third flowerpot and told me, 'Always leave a way back in,' and I still do, in every part of my life.

A concrete object, a real voice, a literal key that turns into a rule for a whole life.

## Run it

```sh
python3 main.py            # writes the sentence to /output/entry.txt
python3 main.py --check    # validate against the 1-200 character gate
python3 main.py --self-test
python3 main.py --tournament
```

Python 3.13, standard library only, no network, no secrets.
